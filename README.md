# Number Guessing Game

A simple interactive console-based Number Guessing Game developed using Core Java as part of my Java Development Internship.

## Features

- Random number generation between 1 and 100
- User input through the console
- Higher and lower hints
- Attempt counter
- Displays the result when the correct number is guessed

## Technologies Used

- Java
- Random Class
- Scanner Class
- Loops and Conditional Statements

## How to Run

1. Clone the repository.
2. Open the project directory.
3. Compile the program:

   ```bash
   javac Main.java
   ```

4. Run the game:

   ```bash
   java Main
   ```

- Understanding Java utility classes
- Working with random number generation
- Implementing loops and conditions
- Handling user input
- Building basic game logic
